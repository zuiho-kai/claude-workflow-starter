# 代码审查

## 什么时候查这里

- 审查代码改动、寻找遗漏、重复实现、错误归属或公开接口影响。

## 不放什么

- 某个仓库专有的审查清单。
- 单次 PR 的完整过程记录。

## 目录内容

| 遇到什么 | 查看哪里 | 说明 |
|---|---|---|
| 从维护者视角审查当前改动，或只拿到 PR 链接 | [独立审查执行合同](guides/review-execution-contract.md) | 同时完成覆盖、减法和 correctness/open review |
| 查找其他审查专项 | [guides 索引](guides/_index.md) | 只继续读取当前风险命中的专项 |
